### 1. ⚡ Intelligent RevOps | Agentic AI

**Deterministic multi-agent AI pipeline for revenue operations with Human-in-the-Loop enforcement**

- **Highlight**: Zero unsanctioned email dispatch — enforced at framework level via CrewAI Flows

- Chris Voss negotiation frameworks mapped to ML output; projected 15pp recovery lift (30% → 45%), $75K MRR incremental gain, 266% ROI
- **Achievement**: ET AI Hackathon Semi-Finalist
- **Tech**: Python, CrewAI Flows, FastAPI, React, scikit-learn, spaCy
- **GitHub**: [Repository](https://github.com/TishyaJ/Intelligent-Rev_Ops)

### 2. 🧠 Medicova AI | Pharmacovigilance Platform

**AI-driven platform for real-time adverse drug reaction detection and classification**

- BioMistral ensemble with QLoRA fine-tuning achieving **Macro F1-Score of 0.94**
- Multimodal evidence collection with AI-powered risk stratification and stakeholder-specific analytics dashboards
- WhatsApp-first data capture using Twilio + ngrok synced with dashboard database; real-time adverse event monitoring
- **Tech**: Python, BioMistral Ensemble, NLP, QLoRA, FastAPI, Twilio
- **GitHub**: [Repository](https://github.com/TishyaJ/Medicova_AI_Pharmacovigilance_Platform)

### 3. 🚀 Saaransh MCA E-Consultation Platform

**AI-powered e-consultation platform for MCA bill analysis using an advanced custom NLP ensemble**

- Custom ensemble of fine-tuned transformers (XLM-RoBERTa, RoBERTa, DistilBERT) with trend-weighted data augmentation
- FAISS + SBERT global deduplication achieving **72% sentiment accuracy (↑7% over baseline)**; OCR-based ingestion cut latency by 40%
- Production-grade FastAPI backend with 44 API endpoints, 95%+ test coverage, and stakeholder-specific analytics dashboards
- **Tech**: FastAPI, PostgreSQL, BERT, FAISS, Docker, OCR
- **Live Demo**: ⭐ [saaransh-mca-e-consutation.vercel.app](https://saaransh-mca-e-consutation.vercel.app/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/TishyaJ/PORTFOLIO.git
cd PORTFOLIO

# Install dependencies
yarn install

# Start the development server
yarn dev
```

### Build for Production

```bash
# Build static export (outputs to /docs)
yarn build
```
